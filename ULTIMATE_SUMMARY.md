## 🚀 Quick Start (5 Minutes)

### For Generating from Scratch:
```bash
# 1. Install dependencies (if you haven't)
npm install @google/genai @ai-sdk/google ai node-vibrant dotenv

# 2. Create .env file with your API key
echo "API_KEY=your_google_ai_studio_key" > .env

# 3. Run the MEGA version!
node completeCardPipeline-MEGA.mjs
```

### For Processing Existing Images:
```bash
# 1. Install dependencies
npm install @ai-sdk/google ai node-vibrant dotenv

# 2. Create .env file
echo "GOOGLE_GENERATIVE_AI_API_KEY=your_key" > .env

# 3. Add images to input_dir/
mkdir input_dir
cp your-images/*.png input_dir/

# 4. Run the MEGA version!
node unifiedCardGenerator-MEGA.mjs
```
